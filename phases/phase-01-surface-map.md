# Phase 1: Lightweight Surface Map (Unauth)

**Framework**: Pure Unauthenticated Bug Bounty  
**Cross-phase coverage**: Read `helpers/coverage-angles.md`.  
This is reconnaissance only. Map observed technologies, protocols, and operation classes to likely angles for later phases.

## Purpose

Build the minimum unauthenticated map required by later phases.  
Prefer a small accurate map to an exhaustive wildcard inventory.

## Steps

1. Collect live hosts from Phase 1a.
2. Light fingerprinting (headers, titles, tech).
3. Note high-value paths and technologies.
4. Record coverage for recon angles.
5. Hand off to Phase 1b/1c and the orchestrator.

## Output

- Surface map summary
- Technology notes
- Coverage delta

## Constraints

- No vulnerability testing.
- Stay inside scope.
- Keep the map bounded.
